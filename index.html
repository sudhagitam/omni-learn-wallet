QUESTION 1 OF 3 (MATH ALGEBRA) Timed Practice

If 3x + 7 = 22, what is the value of 6x - 4?

Step-by-Step Explanation:
1. Solve 3x + 7 = 22 → 3x = 15 → x = 5.
2. Substitute x = 5 into 6x - 4 → 6(5) - 4 = 30 - 4 = 26.
Desmos Graphing Shortcut: Type y = 3x + 7 and y = 22 to find x = 5 visually!

🔥 PyTorch Neural Network Pipeline (Python)

import torch
import torch.nn as nn

class SimpleMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc = nn.Linear(784, 128)
        self.relu = nn.ReLU()
        self.out = nn.Linear(128, 10)
        
    def forward(self, x):
        return self.out(self.relu(self.fc(x)))
